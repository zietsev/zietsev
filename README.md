🧪 Featured Projects

🔹 UAV Multi-Agent Search & Rescue System (GA + Double DQN)
Tech Stack: Python, Reinforcement Learning (DQN, Double DQN), Genetic Algorithm, NumPy, OpenAI Gym (custom env)

Built a multi-agent UAV grid environment for disaster rescue operations with obstacles, wind dynamics, and battery constraints.
Designed a hybrid Genetic Algorithm + Reinforcement Learning system to optimize area coverage, victim detection, and adaptive decision-making.
Implemented reward engineering, risk mapping, and performance metrics (coverage, energy efficiency, detection rate) to improve system intelligence and scalability.

🔹 AI Job Screening System (Agentic AI - Hackathon)
Tech Stack: Python, LLMs, Prompt Engineering, FastAPI, React.js, Node.js, Express.js, MongoDB

Developed a multi-agent AI system to automate job description parsing, CV matching, candidate shortlisting, and interview workflow.
Implemented structured AI pipelines using prompt engineering and agent-based architecture for scalable decision-making.
Built an end-to-end full-stack platform integrating AI models with a responsive frontend and backend APIs.

🔹 Hand Gesture Volume Control System
Tech Stack: Python, OpenCV, MediaPipe, PyAutoGUI

Created a real-time computer vision system to control system volume using hand gesture recognition.
Used hand landmark detection and spatial distance calculations for accurate gesture interpretation.
Enabled touchless human-computer interaction with efficient real-time performance.

🔹 Emergency Ambulance Hiring Portal
Tech Stack: PHP, MySQL, HTML, CSS, JavaScript

Built a web-based platform for booking ambulance services with database integration.
Implemented backend logic for storing, retrieving, and managing user and service data.
Designed a functional UI for real-time service access and request handling.

🔹 QR Code Generator (Dynamic Topic Selector)
Tech Stack: Python

Developed a QR-based system that dynamically generates randomized topics for competitions.
Used automation logic to streamline topic allocation and improve fairness in selection.
